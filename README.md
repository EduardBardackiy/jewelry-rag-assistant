# 💎 Ювелирный Ассистент - RAG Приложение

Интеллектуальный ассистент для ювелирного магазина, использующий технологию RAG (Retrieval-Augmented Generation) для консультирования клиентов.
Это учебный проект, созданный в процессе изучения LangChain и RAG-систем и векторноых БД: FAISS и ChromaDB.

## 🌟 Возможности

- ✅ Обработка документов (PDF, DOCX) с информацией о товарах
- ✅ 🆓 **ЛОКАЛЬНАЯ ОБРАБОТКА ДОКУМЕНТОВ** - больше не нужен платный API!
- ✅ Выбор векторной БД: **FAISS** или **ChromaDB** (в интерфейсе!)
- ✅ Выбор стратегии обработки: **Fast** (быстро) или **Hi-Res** (качественно)
- ✅ Интеллектуальные ответы на вопросы клиентов
- ✅ Рекомендации товаров из каталога
- ✅ Переключение между OpenAI GPT и локальной Llama 3
- ✅ Удобный веб-интерфейс на Streamlit
- ✅ Все настройки в одном месте

## 📋 Требования

- Python 3.9+
- 8GB+ RAM (для локальной модели требуется 16GB+)
- CUDA (опционально, для локальной модели)

## 🚀 Установка

### 1. Клонирование/Скачивание проекта

Проект уже находится в папке `FAISS_ChromaDB`

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

**Активация:**

- Windows:
  ```bash
  venv\Scripts\activate
  ```
- Linux/Mac:
  ```bash
  source venv/bin/activate
  ```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Скопируйте `env_example.txt` в `.env` и заполните своими ключами:

```bash
copy env_example.txt .env
```

Откройте `.env` и укажите:

```env
# Для OpenAI (рекомендуется для начала)
OPENAI_API_KEY=ваш_ключ_openai
MODEL_TYPE=openai

# Или для локальной модели
HUGGINGFACE_TOKEN=ваш_токен_huggingface
MODEL_TYPE=local

# API для обработки документов
UNSTRUCTURED_API_KEY=ваш_ключ_unstructured
```

**Как получить ключи:**

- **OpenAI API**: https://platform.openai.com/api-keys (обязательно для OpenAI модели)
- **Unstructured API**: https://unstructured.io/api-key-hosted (⚠️ ОПЦИОНАЛЬНО - теперь работает локально!)
- **HuggingFace Token**: https://huggingface.co/settings/tokens (только для локальной модели)

### 🆓 Локальная обработка документов (НОВОЕ!)

Теперь вам **НЕ НУЖЕН** платный API ключ Unstructured! 

Просто запустите:
```bash
install-local-unstructured.bat
```

## 🎯 Использование

### Шаг 1: Подготовка данных

Поместите ваши документы (PDF, DOCX) с информацией о товарах в папку `Data/`

### Шаг 2: Запуск приложения

```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу: http://localhost:8501

### Шаг 3: Обработка документов

1. В боковой панели нажмите кнопку **"📄 Обработать документы"**
2. Дождитесь завершения обработки

### Шаг 4: Инициализация системы

1. Нажмите кнопку **"🚀 Инициализировать систему"**
2. Дождитесь загрузки модели

### Шаг 5: Начните общение!

Введите вопрос в поле чата и получите ответ от ассистента.

## 💡 Примеры вопросов

- "Как ухаживать за серебряными украшениями?"
- "Какие серьги подойдут для вечернего мероприятия?"
- "Расскажи о кольцах с бриллиантами"
- "Что нужно знать при выборе ювелирных изделий?"

## ⚙️ Настройки

### Выбор модели

В файле `.env` измените параметр `MODEL_TYPE`:

- `openai` - использовать GPT-4o-mini (требуется API ключ OpenAI)
- `local` - использовать локальную Llama 3 (требуется мощный ПК)

### Редактирование каталога товаров

Отредактируйте файл `catalog.json` или он создастся автоматически с примерами.

## 🔧 Решение проблем

### Ошибка: "UNSTRUCTURED_API_KEY не указан"

Проверьте, что вы:
1. Создали файл `.env` (скопировав `env_example.txt`)
2. Указали ключ `UNSTRUCTURED_API_KEY`

### Ошибка: "FAISS индекс не найден"

Сначала обработайте документы, нажав кнопку **"Обработать документы"**

### Приложение работает медленно

- Используйте `MODEL_TYPE=openai` вместо локальной модели
- Уменьшите количество документов в папке `Data/`
- Проверьте интернет-соединение (для API)

### Не хватает памяти (для локальной модели)

Локальная модель требует минимум 16GB RAM. Используйте `MODEL_TYPE=openai`

## 📚 Технологии

- **Streamlit** - веб-интерфейс с переключением моделей и БД
- **LangChain** - фреймворк для RAG
- **FAISS** / **ChromaDB** - векторные базы данных (выбор в интерфейсе!)
- **OpenAI GPT-4o-mini** / **Llama 3** - языковые модели
- **Unstructured** - 🆓 локальная обработка документов (бесплатно!)
- **HuggingFace** - эмбеддинги и модели

## 🗄️ Выбор векторной БД

Приложение поддерживает две векторные БД:

| БД | Преимущества | Когда использовать |
|----|--------------|-------------------|
| **FAISS** | ⚡ Очень быстрая, простая | Малые данные, прототипы |
| **ChromaDB** | 💿 Персистентная, масштабируемая | Большие данные, продакшен |

**Переключение в интерфейсе:**
1. В sidebar выберите "🗄️ Векторная БД"
2. Выберите FAISS или ChromaDB
3. Обработайте документы (если нужно)
4. Инициализируйте систему
