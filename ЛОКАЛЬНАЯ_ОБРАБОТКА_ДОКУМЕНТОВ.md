# 🆓 Локальная обработка документов (БЕСПЛАТНО!)

## 🎉 Отличная новость!

Теперь проект **полностью поддерживает локальную обработку документов** без использования платного API Unstructured! 

Это означает:
- ✅ **Полностью бесплатно** - не нужен API ключ
- ✅ **Конфиденциально** - документы не отправляются на сторонние серверы
- ✅ **Быстро** - обработка происходит локально на вашем ПК
- ✅ **Поддержка форматов** - PDF, DOCX, DOC, TXT
- ✅ **Два режима** - быстрая и качественная обработка

---

## 📦 Что изменилось?

### Раньше:
- ❌ Требовался платный API ключ Unstructured
- ❌ Документы отправлялись на внешний сервер
- ❌ Зависимость от интернета для обработки

### Сейчас:
- ✅ API ключ **опционален** (можно не указывать)
- ✅ Документы обрабатываются **локально**
- ✅ Работает **без интернета** (после установки пакетов)

## 🚀 Быстрый старт

### Вариант 1: Автоматическая установка (рекомендуется)

Просто запустите:
```batch
install-local-unstructured.bat
```

Это установит все необходимые пакеты за 3-5 минут.

### Вариант 2: Ручная установка

```bash
# Активируйте виртуальное окружение
venv\Scripts\activate

# Установите пакеты
pip install unstructured>=0.11.0
pip install "unstructured[pdf]" pypdf pdf2image pdfminer.six pikepdf
pip install "unstructured[docx]" python-docx python-pptx
pip install Pillow langdetect chardet
```

### ⚠️ Дополнительно: Poppler для стратегии hi_res (опционально)

**Нужен ли Poppler?**
- ❌ **НЕ нужен** для стратегии `fast` (работает отлично без него)
- ✅ **Нужен** для стратегии `hi_res` при обработке PDF файлов
- ❌ **НЕ нужен** для DOCX файлов

**Если вы планируете использовать `hi_res` для PDF:**

📖 **Полная инструкция:** `УСТАНОВКА_POPPLER_WINDOWS.md`

**Кратко:**
1. Скачать: https://github.com/oschwartz10612/poppler-windows/releases
2. Распаковать в `C:\Program Files\poppler`
3. Добавить в PATH: `C:\Program Files\poppler\Library\bin`
4. Перезапустить терминал

**Без Poppler:**
- Стратегия `hi_res` для PDF автоматически переключится на базовую обработку
- Качество будет хорошее, но не максимальное
- Все будет работать, просто без hi_res для PDF

## ⚙️ Настройка

### 1. Файл `.env`

Откройте `.env` и настройте:

```env
# ⚠️ API ключ теперь ОПЦИОНАЛЕН!
# Если не указан - используется локальная обработка
# UNSTRUCTURED_API_KEY=your_api_key_here

# Стратегия локальной обработки
UNSTRUCTURED_STRATEGY=fast
```

### 2. Выбор стратегии

| Стратегия | Скорость | Качество | Требования |
|-----------|----------|----------|------------|
| **fast** | ⚡ Быстро<br>~10-30 сек | ⭐⭐⭐ Хорошее | Базовые пакеты |
| **hi_res** | 🐢 Медленно<br>~1-3 мин | ⭐⭐⭐⭐⭐ Отличное | Доп. пакеты:<br>- Poppler (для PDF)<br>- Tesseract OCR (опционально) |

**Рекомендация**: начните с `fast` - для большинства случаев этого достаточно.

**Важно:** Если вы выбрали `hi_res` и видите ошибки при обработке PDF:
- Установите Poppler (инструкция: `УСТАНОВКА_POPPLER_WINDOWS.md`)
- Или переключитесь на стратегию `fast` (не требует Poppler)

## 🛠️ Технические детали

### Как это работает?

1. **Обнаружение файла**:
   - Приложение сканирует папку `Data/`
   - Определяет тип файла по расширению

2. **Выбор метода обработки**:
   - Если есть `UNSTRUCTURED_API_KEY` → используется API
   - Если нет ключа → локальная обработка

3. **Локальная обработка**:
   - `unstructured` библиотека обрабатывает файл
   - Извлекается текст, структура, метаданные
   - Поддержка русского и английского языков

4. **Создание индекса**:
   - Текст разбивается на чанки
   - Создаются эмбеддинги (векторы)
   - Сохраняется в FAISS или ChromaDB

### Используемые библиотеки

| Библиотека | Назначение |
|------------|------------|
| `unstructured` | Основная библиотека для обработки |
| `pypdf` | Чтение PDF файлов |
| `pdf2image` | Конвертация PDF в изображения |
| `pdfminer.six` | Извлечение текста из PDF |
| `pikepdf` | Работа с защищенными PDF |
| `python-docx` | Обработка DOCX файлов |
| `python-pptx` | Обработка PPTX файлов |
| `Pillow` | Обработка изображений |
| `langdetect` | Определение языка текста |
| `chardet` | Определение кодировки |

## 🐛 Решение проблем

### Проблема: "ModuleNotFoundError: No module named 'unstructured'"

**Решение**:
```bash
pip install unstructured
```

### Проблема: "PDF не обрабатывается"

**Решение**:
```bash
pip install "unstructured[pdf]" pypdf pdf2image pdfminer.six pikepdf
```

### Проблема: "DOCX не обрабатывается"

**Решение**:
```bash
pip install "unstructured[docx]" python-docx
```

### Проблема: "Unable to get page count. Is poppler installed and in PATH?"

**Причина:** Вы используете стратегию `hi_res` для PDF, но Poppler не установлен.

**Решения:**

**Вариант 1 (ПРОЩЕ):** Переключитесь на стратегию `fast`:
```env
UNSTRUCTURED_STRATEGY=fast
```
→ Не требует Poppler, качество хорошее для большинства задач

**Вариант 2:** Установите Poppler:
- 📖 Инструкция: `УСТАНОВКА_POPPLER_WINDOWS.md`
- Скачать: https://github.com/oschwartz10612/poppler-windows/releases
→ Максимальное качество обработки PDF

### Проблема: "Медленная обработка при hi_res"

**Решения**:
1. Переключитесь на стратегию `fast`:
   ```env
   UNSTRUCTURED_STRATEGY=fast
   ```

2. Установите Tesseract OCR (опционально):
   - Windows: https://github.com/UB-Mannheim/tesseract/wiki
   - После установки добавьте в PATH

### Проблема: "Ошибка при обработке защищенных PDF"

**Решение**:
```bash
pip install pikepdf
```

Если не помогло - снимите защиту с PDF перед обработкой.

### Проблема: "Плохое качество распознавания текста"

**Решения**:
1. Переключитесь на стратегию `hi_res`
2. Установите Tesseract OCR
3. Или используйте API вместо локальной обработки

## 🎯 Итоги

### ✅ Преимущества локальной обработки:

1. **Бесплатно** - экономия на API
2. **Конфиденциально** - данные остаются у вас
3. **Просто** - один bat-файл для установки
4. **Быстро** - достаточно для большинства задач
5. **Автономно** - работает без интернета

### ⚠️ Когда лучше использовать API:

1. Нужно максимальное качество OCR
2. Много сложных документов с таблицами
3. Критична скорость обработки
4. Есть бюджет на API

### 🎉 Лучшее из двух миров:

Вы можете **переключаться** между локальной обработкой и API:
- Для простых документов → локально (бесплатно)
- Для сложных документов → API (качественно)

Просто добавьте/уберите `UNSTRUCTURED_API_KEY` в `.env`!
