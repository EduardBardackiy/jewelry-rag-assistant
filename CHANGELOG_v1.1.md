## 🆓 Что нового?

### Локальная обработка документов (БЕСПЛАТНО!)

Теперь проект **больше не требует** платный API Unstructured! Все документы могут обрабатываться локально на вашем компьютере совершенно бесплатно.

#### ✅ Преимущества:
- **Бесплатно** - экономия на API (~$0.01-0.10 за документ)
- **Конфиденциально** - документы остаются на вашем ПК
- **Автономно** - работает без интернета (после установки пакетов)
- **Быстро** - обработка за 10-30 секунд
- **Гибко** - выбор между быстрой и качественной обработкой

## 🎯 Новый функционал

### 1. Выбор стратегии обработки в интерфейсе

Пользователь может выбрать между двумя стратегиями:

| Стратегия | Описание | Время | Качество |
|-----------|----------|-------|----------|
| **fast** | Быстрая обработка | ~10-30 сек | ⭐⭐⭐ Хорошее |
| **hi_res** | Качественная обработка | ~1-3 мин | ⭐⭐⭐⭐⭐ Отличное |

Выбор сохраняется в `.env` и применяется ко всем последующим обработкам.

### 2. Автоматическое определение режима обработки

Система автоматически определяет, какой метод обработки использовать:

```python
if UNSTRUCTURED_API_KEY существует и валиден:
    использовать API (платно)
else:
    использовать локальную обработку (бесплатно)
```

### 3. Информативный статус в интерфейсе

Пользователь всегда видит:
- Текущую стратегию обработки
- Используется ли API или локальная обработка
- Рекомендации при изменении настроек

### 4. Graceful degradation

Если пользователь выбрал `hi_res`, но не установлены необходимые пакеты:
- Система автоматически переключится на `fast`
- Выведет предупреждение
- Продолжит работу без ошибок

### 5. Поддержка разных форматов с оптимизацией

Для каждого типа файла применяются оптимальные параметры:

**PDF:**
- Поддержка русского и английского языков
- Включение page breaks
- Распознавание таблиц (в режиме hi_res)

**DOCX/DOC:**
- Поддержка русского и английского языков
- Сохранение структуры документа

**TXT:**
- Прямая обработка текста

## 🐛 Известные ограничения

### 1. Hi-Res стратегия на Windows

**Проблема:** Для стратегии `hi_res` требуется Tesseract OCR, который не всегда легко установить на Windows.

**Решение:** Используйте стратегию `fast` или установите Tesseract из:
https://github.com/UB-Mannheim/tesseract/wiki

### 2. Защищенные PDF

**Проблема:** Некоторые защищенные PDF могут не обрабатываться.

**Решение:** Снимите защиту или используйте API.

### 3. Сложные таблицы

**Проблема:** Локальная обработка может хуже распознавать сложные таблицы по сравнению с API.

**Решение:** 
- Используйте стратегию `hi_res`
- Или переключитесь на API для таких документов
