# 🔧 Установка Poppler для Windows

## Что такое Poppler?

Poppler - это набор утилит для работы с PDF файлами. Он нужен для стратегии `hi_res` при обработке PDF документов.

---

## 📥 Установка

### Способ 1: Скачать готовую сборку (РЕКОМЕНДУЕТСЯ)

1. **Скачайте Poppler для Windows:**
   - Перейдите: https://github.com/oschwartz10612/poppler-windows/releases
   - Скачайте последнюю версию (например: `Release-24.08.0-0.zip`)

2. **Распакуйте архив:**
   - Распакуйте в удобное место, например: `C:\Program Files\poppler`
   - Структура должна быть: `C:\Program Files\poppler\Library\bin\`

3. **Добавьте в PATH:**
   
   **Через графический интерфейс:**
   - Нажмите `Win + X` → "Система"
   - Справа выберите "Дополнительные параметры системы"
   - Нажмите "Переменные среды"
   - В разделе "Системные переменные" найдите `Path`
   - Нажмите "Изменить"
   - Нажмите "Создать"
   - Добавьте путь: `C:\Program Files\poppler\Library\bin`
   - Нажмите "ОК" везде
   
   **Через PowerShell (от администратора):**
   ```powershell
   [Environment]::SetEnvironmentVariable("Path", $env:Path + ";C:\Program Files\poppler\Library\bin", "Machine")
   ```

4. **Перезапустите терминал/PowerShell**

5. **Проверьте установку:**
   ```bash
   pdfinfo -v
   ```
   
   Должна появиться версия poppler.

---

### Способ 2: Через Chocolatey

Если у вас установлен Chocolatey:

```bash
choco install poppler
```

---

## ✅ После установки

1. **Перезапустите приложение** (закройте и откройте заново)
2. **Обработайте документы снова** с стратегией `hi_res`
3. **PDF файлы теперь обработаются с высоким качеством!**

## 🐛 Решение проблем

### Проблема: "pdfinfo не распознан как команда"

**Решение:** PATH не обновился
- Перезапустите PowerShell/CMD
- Или перезагрузите компьютер
- Проверьте путь в переменных окружения

### Проблема: "Unable to get page count" все еще появляется

**Решение:** Проверьте путь
```bash
# В PowerShell
$env:Path
```

Должен быть путь к poppler\Library\bin

### Проблема: Не хочу устанавливать poppler

**Решение:** Используйте стратегию `fast`
- Она работает без poppler
- Для большинства случаев качество достаточное
- Быстрее обработка

---

## 📊 Сравнение с poppler и без

| Параметр | Без poppler (fallback) | С poppler (hi_res) |
|----------|----------------------|-------------------|
| **Качество** | ⭐⭐⭐ Хорошее | ⭐⭐⭐⭐⭐ Отличное |
| **Скорость** | ⚡ Быстро (~10 сек) | 🐢 Медленно (~1-3 мин) |
| **Таблицы** | ⚠️ Базово | ✅ Отлично |
| **Изображения** | ⚠️ Базово | ✅ OCR с распознаванием |
| **Структура** | ⚠️ Частично | ✅ Полностью |

## 💡 Рекомендации

### Используйте hi_res + poppler если:
- Нужно максимальное качество OCR
- Документы содержат сложные таблицы
- Важна точность структуры документа
- Есть сканированные изображения

### Используйте fast (без poppler) если:
- Обычные текстовые PDF
- Важна скорость обработки
- Не критична идеальная точность
- Хотите простоту (без установки доп. утилит)

---

## 🎯 Итог

**Самый простой путь:**
1. Используйте стратегию `fast` - она не требует poppler
2. Для 90% случаев этого достаточно

**Для максимального качества:**
1. Установите poppler (5-10 минут)
2. Используйте стратегию `hi_res`
3. Получите лучшее качество OCR и распознавания структуры
